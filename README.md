
# Go Backend Mini-Projects
A collection of five standalone Go applications built to demonstrate core backend engineering concepts. Each project is scoped to solve a specific problem using the Go standard library:


* **01-unit-converter:** A CLI tool for converting units (temperature) using explicit pure function signatures, input validation and flag parsing.
* **02-log-analyzer:** A file-streaming CLI tool for parsing HTTP server logs and calculating status metrics.
* **03-key-value-store:** An in-memory NoSQL database engine featuring JSON disk persistence.
* **04-task-api:** A zero-dependency RESTful API with custom HTTP request/response middleware.
* **05-health-checker:** A concurrent URL health monitoring tool utilizing goroutines, channels, and worker pools.
